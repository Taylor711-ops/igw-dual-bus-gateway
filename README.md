# 智联双总线工业协议融合网关系统

本仓库准备公开比赛作品的主要技术源码、工程配置及说明。系统由安路 FPGA/Linux 主机、支持 CAN 和 RS485 的安路从机（逻辑设备 1、2）以及 RS485 Zynq 设备 3 组成。

## 功能与代码

- `01_FPGA_MAIN/`：安路主机 RTL、项目配置、设备树及 CAN 驱动参考。
- `02_MONITOR/`：监控网页、CAN/RS485 通信、归档、NPU、安路从机和设备 3 数值通信。
- `03_FILE_TRANSFER/`：SD 文件服务、Zynq 文件收发以及 CAN 设备 1 与 RS485 设备 3 的定向并行文件服务和网页。
- `90_REFERENCE/`：历史参考版本，并非默认的当前部署版本。

详细版本关系、构建环境和现场测试范围见 [README_请先阅读.md](README_请先阅读.md)。这些是迭代版本，不能将全部源文件放进同一个工程编译。设备 1、2 为一块物理从机上的两个逻辑设备；设备 3 为另一块 Zynq 板；所有 RS485 节点共享一条半双工总线。

已记录的板测包括设备 3 的 RS485 文件收发，以及在设备 3 的 RS485 文件任务期间启动设备 1 的 CAN 文件任务，两项 65536 字节传输在网页上均显示校验通过。该结果仅对应所述组合，不等同于所有设备组合、长期稳定性或断电恢复均已验证。

## 获取依赖与构建

安路硬件工程需要相应安路 TD、厂商 IP 和板卡资料；Linux 主机程序需要 AArch64 交叉编译器，NPU 程序还需对应 SDK；Zynq 工程使用 Vivado/Vitis 2020.2 和 xilffs。具体入口和依赖见各工程 README。

**公开快照不含安路生成 IP、预编译启动镜像和部分嵌套原始压缩包。** 恢复或构建相关工程时须从有权使用的原工程或开发工具取得或重新生成对应文件。本仓库不是整板镜像，也不是无需厂商依赖的一键构建包。排除的文件清单及其原始哈希见 [PUBLICATION_EXCLUDED.tsv](PUBLICATION_EXCLUDED.tsv)。

各子目录原始的校验清单记录的是原始发布包；由于公开快照有上述排除项，直接检查历史清单可能提示缺失。根目录 `SHA256SUMS.txt` 则对应本公开快照。原版本功能、部署路径和当时的验证状态应结合原文件日期理解。
